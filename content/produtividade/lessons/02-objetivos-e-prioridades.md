# Objetivos e prioridades

Uma lista grande de pendências não é um plano. Priorizar é decidir o que merece atenção agora e aceitar que algumas tarefas ficarão para depois.

Comece separando objetivos de tarefas. “Aprender JavaScript” é um objetivo de longo prazo. “Fazer a aula de operadores e resolver três exercícios” é uma tarefa concreta. Objetivos dão direção; tarefas colocam o plano em movimento.

## Escolhendo a próxima tarefa

Antes de começar a semana, liste suas entregas e pergunte: qual delas tem prazo, destrava outra atividade ou ensina uma base importante? Escolha de uma a três prioridades. Se tudo é prioridade, nada recebe foco real.

Uma prioridade pode ser dividida assim:

1. Resultado: terminar uma página de cadastro.
2. Próxima entrega: validar os campos obrigatórios.
3. Próxima ação: localizar o arquivo do formulário e listar os campos.

O último item é o que entra na sessão de trabalho. Ele elimina a dúvida de como começar.

### Erros comuns

- Planejar dez tarefas importantes para o mesmo dia.
- Confundir urgência de uma mensagem com importância para o curso ou projeto.
- Manter tarefas vagas por semanas.

### Exercícios

1. Transforme dois objetivos seus em tarefas observáveis.
2. Escolha suas três prioridades da próxima semana e explique por que cada uma vem antes das demais.

### Atividade prática

Prepare uma lista para amanhã com uma prioridade principal, uma tarefa de apoio e uma tarefa simples para encerrar o dia.
