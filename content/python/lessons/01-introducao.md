# Introdução à programação e ao Python

Programar é escrever instruções para que o computador execute uma tarefa. Um programa pode calcular uma média, organizar uma lista ou conversar com uma pessoa pelo terminal.

Python é uma linguagem conhecida por ter uma escrita clara. Para mostrar uma mensagem, usamos `print`:

```python
print("Olá, mundo!")
```

Quando o programa chega a essa linha, ele exibe o texto entre aspas. As aspas indicam que aquilo é um texto, e os parênteses fazem parte da chamada da função `print`.

Experimente alterar a frase e executá-la novamente. Errar, ler a mensagem e tentar de novo faz parte do aprendizado.

Um comentário começa com `#`. Ele serve para explicar o código e não é executado:

```python
# Esta linha explica a próxima instrução
print("Estou aprendendo Python")
```

### Exercícios

2. Escreva duas linhas usando `print` para contar algo sobre você.
