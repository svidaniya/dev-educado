# Operadores e cálculos

Operadores permitem combinar valores. Os mais comuns são `+` para somar, `-` para subtrair, `*` para multiplicar e `/` para dividir.

```python
preco = 12.50
quantidade = 3
total = preco * quantidade
print(total)
```

O programa multiplica `12.50` por `3` e guarda o resultado em `total`. Também existem `//` para divisão inteira e `%` para o resto de uma divisão.

```python
numero = 17
print(numero % 2)
```

O resultado é `1`, porque sobra 1 ao dividir 17 por 2. Isso ajuda a descobrir se um número é par ou ímpar.

Com textos, `+` junta valores:

```python
nome = "Lia"
mensagem = "Olá, " + nome
print(mensagem)
```
