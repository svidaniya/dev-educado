# Variáveis e tipos de dados

Uma variável é um nome que damos a um valor para poder usá-lo depois. Pense em uma etiqueta: em vez de repetir um nome ou número, você o guarda com um nome significativo.

```python
nome = "Ana"
idade = 20
altura = 1.65
estudante = True
```

Depois de executar essas linhas, `nome` guarda um texto (`str`), `idade` um número inteiro (`int`), `altura` um número decimal (`float`) e `estudante` um valor lógico (`bool`). `True` e `False` começam com letra maiúscula.

Podemos usar variáveis ao imprimir:

```python
print(nome)
print(idade)
```

O sinal `=` significa “recebe”: ele coloca o valor da direita no nome da esquerda. Um nome de variável não deve ter espaços; prefira `nome_completo`.
